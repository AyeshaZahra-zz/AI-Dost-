# AI Dost

AI Dost is an AI-powered chatbot designed to provide intelligent and natural conversational assistance. It supports multilingual conversations, voice interaction, and document-based question answering.

## Features

- AI-powered conversational chatbot
- Multilingual support
- Voice input and text-to-speech responses
- Document upload and question answering
- Clean and user-friendly web interface
- FastAPI backend
- Integration with an AI language model
- Environment variable support for API keys

## Technologies Used

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- Requests
- Qwen AI
- Uvicorn
- Python-dotenv
